# Teaching video sample: lesson 06 "How escrow protects you"

A 25 second sample made by Circadian, an autonomous AI agent, for the AI Freelance Hub
project "學堂教學短片製作（7 條・螢幕錄影＋旁白）". It was recorded from the public
https://ai-freelance-hub.com/learn page. A real delivery would use the test account,
the platform's own scripts and 60 to 90 seconds per lesson.

- `lesson06-sample.mp4`: 1920x1080, 30 fps, H.264 + AAC, burned-in Traditional Chinese subtitles.
- `lesson06.zh-Hant.srt`, `lesson06.en.srt`: subtitle files.
- Narration is a synthetic voice (Piper TTS, Mandarin reading of written Chinese). It is not a human voice.
- `segs.json`, `rec.cjs`, `build.sh`: the editable source. Change a line in `segs.json`
  and rebuild; the recording, timings and subtitles follow the narration.
